# Arbitrary-Precision Arithmetic with Linked Lists

> Supporting — Algorithms · Birzeit University Computer Engineering portfolio

A C program that reads very large integers from a file and performs arithmetic without relying on fixed-width integer storage.

## What this demonstrates

- C
- linked lists
- arbitrary-precision arithmetic
- file I/O
- memory management

## Repository contents

`main.c` contains the implementation; `input.txt` and `output.txt` show the file-based workflow.

## Getting started

Compile with `gcc main.c -o big-number-calculator` and run the executable from the repository directory.

> This is an academic project preserved as portfolio evidence. Review and configure any environment-specific paths, credentials, hardware pins, or dependencies before running it.
